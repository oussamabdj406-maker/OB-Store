O&B STORE — Landing Page gratuite
==================================

Contenu:
- index.html : page d'accueil responsive (arabe RTL), style noir et doré.
- Le formulaire de commande est une maquette front-end : il ne transmet pas encore les commandes au propriétaire.
- Les produits, prix, images, numéro WhatsApp et moyen de réception des commandes restent à personnaliser.

Publication gratuite avec GitHub Pages:
1. Connecte-toi à GitHub et ouvre ton dépôt.
2. Clique sur Add file > Upload files.
3. Envoie index.html (pas nécessaire d'envoyer README.md si tu ne veux pas).
4. Si GitHub demande un commit, valide-le.
5. Dans Settings > Pages, choisis la branche principale (souvent main) et le dossier / (root), puis Save.
6. Ouvre le lien GitHub Pages affiché dans Settings > Pages.

À personnaliser ensuite:
- Remplacer les trois cartes exemples par les vrais produits.
- Ajouter photos réelles et prix.
- Pour que les commandes arrivent réellement, relier le formulaire à une solution gratuite de formulaires ou configurer WhatsApp avec ton numéro. Ne publie pas de faux prix ou de coordonnées.
